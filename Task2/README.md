# Task 2: Responsive Landing Page

## 📌 About the Project
This project is a responsive landing page created as part of my Web Development Internship at Kodbud. The goal was to design an attractive homepage for a fictional startup or product that works across desktop and mobile devices.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox and/or CSS Grid

## ✨ Features
- Responsive layout for mobile and desktop screens
- Modern header and navigation section
- Feature highlights section
- Testimonials section
- Clean footer design
- Organized layout and styling

## 🚀 How to Run
1. Download or clone this repository.
2. Open the `index.html` file in your web browser.

## 🎯 Learning Outcomes
- Understanding responsive web design
- Using Flexbox and CSS Grid
- Structuring landing page sections
- Improving UI layout and styling skills
