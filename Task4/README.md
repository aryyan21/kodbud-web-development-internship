# Task 4: Responsive Image Gallery

## 📌 About the Project
This project is a responsive image gallery built as part of my Web Development Internship at Kodbud. It focuses on presenting images in an organized layout that adapts to different screen sizes.

## 🛠️ Technologies Used
- HTML5
- CSS3
- CSS Grid and/or Flexbox

## ✨ Features
- Responsive image gallery layout
- Three-column image arrangement on desktop (if implemented)
- Single-column layout on mobile (if implemented)
- Organized image spacing and alignment
- Clean and visually appealing presentation

## 🚀 How to Run
1. Download or clone this repository.
2. Open the `index.html` file in your web browser.
3. Ensure the image files are in the correct folder so they display properly.

## 🎯 Learning Outcomes
- Understanding CSS Grid and Flexbox
- Building responsive layouts
- Managing images and file paths
- Improving visual presentation across devices
